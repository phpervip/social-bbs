⭐ Logo & 设计原则

B
B
纯 CSS 实现 · 咖啡棕渐变圆角方块 + 粗体字母
少即是多：核心信息优先，无装饰元素；卡片无边框，用间距与留白分隔内容
黑白 + 咖啡棕：页面以深色/浅色中性色为主，咖啡棕（#8B5A2B）仅用于 Logo、链接、主按钮、选中态 — 避开 X.com 蓝/黑白雷同
克制动效：仅 hover 颜色过渡（150ms）、骨架屏加载（skeleton）、下拉刷新；无弹跳/缩放花哨动画
中文优先：字体栈 system-ui, -apple-system, "PingFang SC", "Microsoft YaHei"，字号 14px 基准，行高 1.5

⭐ 关键页面布局

布局骨架：三栏（桌面）— 左栏导航（固定 260px）+ 中栏内容流（弹性）+ 右栏推荐（固定 320px，≤1024px 隐藏）；移动端单栏，导航收为底部 TabBar（首页/探索/通知/我的）

首页时间线：帖子卡片纵向流 — 头像 + 用户名 + 时间 + 内容 + 媒体（图/视频封面）+ 操作行（点赞/评论/转发，数字轻量展示）；下拉刷新 + 滚动加载（游标分页）

发帖：Modal 弹出 — 文本区 + 图片/视频上传（分片直传 S3 预签名）+ 发布按钮（咖啡棕实底）；280 字计数，超限禁用

视频页：16:9 播放器（HLS.js）+ 标题/作者/点赞评论 + 相关推荐列表；封面懒加载 + 播放时自动暂停其他

个人主页：封面渐变条 + 头像/昵称/简介 + 关注/粉丝/帖子统计 + Tab（帖子/视频/喜欢）

通知：右侧抽屉 — 分组（提及/点赞/评论/关注/系统），WS 实时推送红点徽标，未读高亮 + 已读标记

组件规范

共享组件（Shell 提供）：Avatar / Button / Skeleton / Modal / Toast / EmptyState — Remotes 通过 MF 复用，禁止各自重写

状态：loading → 骨架屏；empty → 空状态插画 + 引导文案；error → 轻量错误提示 + 重试按钮

交互反馈：点赞/关注/转发即时乐观更新（UI 先行，失败回滚 + Toast）

暗色模式：CSS 变量切换（[data-theme="dark"]），跟随系统 + 手动切换

性能 & 工程规范

代码分割：MF Remote 按需加载（import()），首屏仅 Shell + 当前 Remote

图片：CDN 缩略图参数（?w=480&q=75）· loading="lazy" · 头像统一 48px 裁切

缓存：静态资源 Cache-Control: immutable（内容哈希文件名）· API 响应 5min 缓存（GET）

错误边界：每个 Remote 外层 ErrorBoundary，子应用崩溃仅显示局部占位，不影响 Shell 与其他 Remote
