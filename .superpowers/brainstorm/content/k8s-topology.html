⭐ 服务发现 & 网络

K8s Service（ClusterIP）：每个微服务暴露 {service-name}.default.svc.cluster.local 内部 DNS，gRPC 直连 · 前端静态资源经 Ingress 路由 b.local → gateway · WebSocket 走 Ingress annotations（upgrade 头透传）
Nginx Ingress 规则：b.local/api/* → gateway:8080（HTTP）· b.local/ws/* → gateway:8081（WebSocket）· b.local/hls/* → hls 静态服务
跨服务调用：统一走 gRPC（user-service:9000 / feed-service:9000 / video-service:9000 / search-service:9000），Kafka 事件总线经 kafka:9092 · 配置用 ConfigMap 下发，密钥用 Secret

部署策略

Deployment ×2 副本（无状态微服务）：滚动更新 maxSurge=1 / maxUnavailable=0 · 存活/就绪探针（/healthz gRPC 健康检查）
StatefulSet ×1（MySQL/Redis/Kafka/ES/MinIO）：PVC 持久化，Pod 重建数据不丢 · 有状态服务不做水平扩容（演示环境）
FFmpeg Worker：任务消费组件，从 Kafka 消费转码任务 · 依靠分布式锁防止重复消费（video:transcode-task 事件 + Redis 锁，同一任务只被一个 Worker 处理）· 失败重试 3 次 + 死信
资源限制：requests/limits 按服务配置（CPU/内存），防止 Pod 互相挤占

外部依赖（本地模拟）

MinIO：替代 AWS S3（桶：videos / uploads / avatars）· 预签名 URL 直传/直读
HLS 静态服务：Nginx 容器 serve .m3u8 / .ts 文件（MinIO 桶挂载或 CDN 直读）
本机 hosts：127.0.0.1 b.local → NodePort 80 → Ingress
演示说明：生产环境对应 AWS S3 + CloudFront CDN + Imperva WAF，本机用 MinIO + Nginx 等价替代

⚠️ 环境说明：Kind 仅用于本地架构演示，禁止生产部署

集群局限：单宿主机运行，无硬件故障容灾；Local PV 不支持 Pod 跨节点迁移（节点宕机数据不可达）
中间件简化：Kafka 单节点、Redis 单实例、ES 无副本 — 均为演示简化；生产部署需多副本（Kafka ≥3 节点、Redis 主从/集群、ES 多副本）保障数据安全

⭐ 扩展规划 & 扩缩容

监控：可接入 Prometheus + Grafana（指标采集 / 可视化面板）· Loki 日志聚合系统 · NetworkPolicy 网络隔离（默认拒绝 + 白名单放行）
HPA 自动扩缩容：业务微服务（gateway / user / feed / video / notification / search）支持 HPA（CPU/内存阈值触发）· 有状态组件（MySQL / Kafka / ES / Redis）不启用 HPA（扩容需人工评估数据分片/副本策略）
